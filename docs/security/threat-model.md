# Threat model

## Assets and boundaries

Assets are OAuth tokens, normalized posts/comments, inferred interests, feedback, summaries, source URLs, jobs, and model configuration. Boundaries are source → connector, connector → Rust core, core → local model, core → SQLite/vault, and core → renderer.

| Threat                                                   | Current controls                                                                                                                                                                                                                                                                                                                              | Residual risk                                                                                                                          |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Malicious feed text causes script/IPC activity           | XML parsed in Rust; HTML/control text stripped; bounded strings; React text rendering; restrictive CSP; no remote navigation or renderer plugins                                                                                                                                                                                              | Parser/WebView defects require prompt patching                                                                                         |
| Indirect prompt injection takes actions or leaks secrets | Evidence is an explicit JSON data field; reader model has no tools, network, DB, connector, or secrets; schema/length validation                                                                                                                                                                                                              | A model can still write a misleading summary; evidence remains visible                                                                 |
| RSS SSRF/DNS rebinding                                   | HTTP(S) only; no credentials/fragments/proxies; conservative IPv4/IPv6 policy rejects mixed/private, mapped, NAT64, 6to4, transition, reserved, loopback, link-local, shared, multicast, and documentation answers; validated addresses are pinned for the connection; every redirect is independently revalidated and HTTPS cannot downgrade | Public destinations and DNS can still change behavior after connection; keep the IANA special-range policy and transport tests current |
| Oversized/decompression payload                          | 2 MB advertised and streamed RSS caps, 100-post batch cap, 50 comments/post, 500 comments and 256 KiB comment text/batch, 4,000 bytes/comment, depth 8, 15-second RSS timeout, three redirects                                                                                                                                                | Compression handling and future official API decoders require fuzzing                                                                  |
| Disabled social connector activated accidentally         | Backend-owned descriptors mark Mastodon validation-required and Bluesky blocked; no OAuth commands, browser launch, credential fields, provider modules, or renderer permissions exist; only RSS is available                                                                                                                                 | Future activation requires fresh OAuth/provider policy, egress, vault, callback, moderation, and deletion review                       |
| Token theft from disk/logs                               | OS credential vault (Windows Credential Manager, macOS Keychain, Linux Secret Service); opaque DB reference only; fail closed if unavailable; no token command/DTO; activity uses counts/stable text                                                                                                                                          | Same-user malware can access app process and often the vault; headless Linux sessions may lack a usable Secret Service                 |
| Renderer compromise invokes privilege                    | Named serde commands, size/range validation, no arbitrary SQL/HTTP/fs/shell/process, minimal capabilities                                                                                                                                                                                                                                     | Every new command expands review surface                                                                                               |
| Rogue localhost model                                    | Fixed numeric loopback endpoint; system proxies and redirects disabled; stream-bounded response; installed-model check plus bounded structured-generation probe; exact digest re-attested before/after generation; typed fallback states                                                                                                      | Another same-user process can impersonate the unauthenticated local runtime; deterministic evidence remains visible                    |
| Database corruption or duplicate work                    | Version-gated transactional migrations, FK, WAL, busy timeout, payload-bound request receipts, typed fail-closed Unknown finality, source generations, renewable owner/fencing-token runner leases, compare-and-set finish, reopen/idempotency/fake-time tests                                                                                | Online backup/restore, abrupt-kill at every boundary, and real multi-process soak remain release work                                  |
| Deletion incompleteness                                  | Sync/delete serialization, durable source-generation tombstone, exact-generation ingest, random tombstone-owned deletion replay capability, Unknown transformation for erased add/feedback bindings, FK cascades, idempotent vault-first deletion, non-identifying audit event, explicit backup disclosure                                    | SSD/WAL/OS backups may retain bytes; source tombstones retain the opaque local source identifier and random replay association         |
| Supply-chain/update compromise                           | Lockfiles and no runtime executable downloads in foundation                                                                                                                                                                                                                                                                                   | Signed installer/update, SBOM, audits, and protected signer are required before release                                                |

## Security invariants

1. No write scopes or model-triggered side effects.
2. No secrets or social text in logs, telemetry, renderer persistence, or exports.
3. No cloud inference/telemetry fallback.
4. No remote HTML, app-webview navigation, cookie import, stealth, CAPTCHA bypass, or identity/proxy rotation.
5. SQLite content is not application-encrypted; the UI must accurately describe reliance on OS permissions/full-disk protection.
6. Connector, model, and IPC inputs are length/type/URL validated in Rust.
7. Failure of the secure credential store never causes plaintext persistence.

## Verification still required before public release

Fuzz RSS/XML and model responses, seed a canary secret and scan DB/logs/bundles, instrument all egress, test DNS rebinding, kill the process at each job transaction boundary, exercise low disk/locked vault/sleep-wake, audit CSP in packaged WebView2/WebKit/WebKitGTK, sign Windows packages, sign/notarize macOS packages, validate Linux packages, and complete dependency/license/secret scanning.
