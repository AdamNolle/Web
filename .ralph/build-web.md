# Build Web — local-first social media digest

Create a production-minded **Windows, macOS, and Linux** desktop app named **Web** that replaces compulsive social checking with deliberate, scheduled digests generated by local models.

## Product decisions

- Tauri 2 is the cross-platform desktop foundation. React is presentation-only; Rust owns persistence, connectors, jobs, secrets, network policy, host capability detection, and inference.
- Official APIs are preferred. Opt-in browser connectors may be transparent, low-frequency, and user-controlled only.
- Do **not** implement proxy/identity rotation, stealth fingerprinting, CAPTCHA bypass, session-cookie import, credential interception, or anti-bot evasion.
- Credentials stay local in the OS vault (Windows Credential Manager, macOS Keychain, Linux Secret Service) behind `SecretStore`. Missing/locked vaults fail closed; there is no plaintext fallback.
- Social content is untrusted data, never model instructions. The summarizer gets no tools, credentials, or side-effect capabilities.
- Host-adaptive model profiles are conservative suggestions, never silent downloads or cloud fallback. GPU, battery, and metered-network states remain `unknown` when not reliably detectable.
- Be honest about platform API limits: v1 targets RSS/Atom, Bluesky, and Mastodon. YouTube is subscriptions-derived; Reddit/X are gated; Meta/LinkedIn/TikTok home feeds are not advertised.

## Goals

- A polished Tauri 2 + React + TypeScript desktop app with narrow typed commands and restrictive capabilities/CSP.
- SQLite persistence and a stable built-in adapter SDK for social/API/RSS/browser connectors.
- Working fixture/demo and RSS paths plus representative Bluesky/Mastodon connectors where feasible.
- Ollama/OpenAI-compatible local LLM integration with structured-output validation and deterministic fallback summaries.
- Manual and scheduled sync, digest generation, comment overview, local trends, and interpretable explicit-feedback importance learning.
- Calm, accessible, finite editions with no infinite scroll, autoplay, vanity counters, streaks, or engagement traps.
- Security/privacy controls, retention, delete/export, prompt-injection defenses, egress visibility, and diagnostics.
- Unit/integration/component tests, cross-platform build verification, and complete operator/developer documentation.
